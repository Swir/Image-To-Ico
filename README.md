## 🇬🇧 English

Image To ICO is a graphical Python utility for converting PNG/JPG images into Windows `.ico` files. It provides image selection, preview and a simple save workflow from a compact Tkinter interface.

### ✨ Features
- select PNG and JPG images
- preview the selected image
- add/remove source images
- save output as `.ico`
- straightforward desktop GUI
- executable build directory included in the repository

### 🚀 Installation

```bash
git clone https://github.com/Swir/Image-To-Ico.git
cd Image-To-Ico
pip install -r requirements.txt
python ikona.py
```
