## 🚀 About

**Image To ICO** is a lightweight Python desktop converter for turning PNG and JPG images into Windows `.ico` icon files. The graphical interface lets you select source images, preview them and save the result as an icon without using command-line image tools.

It is designed for users searching for a **PNG to ICO converter**, **JPG to ICO converter**, **Python icon converter**, **ICO maker for Windows**, **Tkinter image converter** or a simple desktop icon-generation utility.
